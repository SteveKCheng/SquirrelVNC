# Notes on the icons in the toolbar

## Old 16×16 icons used by TightVNC

| Icon function | Description of TightVNC's icon |
| - | - |
| New connection… | Two computers connected to each other |
| Save session to a .vnc file | 3½" floppy disk |
| Connection options… | Hand pointing to a piece of paper with a list written on it |
| Connection info… | Sheet of paper folded in upper-right corner, with “i” written on it |
| Pause | Pause symbol from audio/video players |
| Request screen refresh | Two arrows arranged in a circle/cycle |
| Send Ctrl+Alt+Del | Three keyboard keys |
| Send Ctrl+Esc | Old-style Windows logo |
| Ctrl key down | The text “Ctrl” |
| Alt key down | The text “Alt” |
| Transfer files… | Two sheets of paper with lines of text on them, one sheet folded in upper-right corner |
| Scale in | Magnifying glass with “+” symbol in its viewport |
| Scale out | Magnifying glass with “-” symbol in its viewport |
| Scale: 100% | Magnifying glass with “100” written on its viewport |
| Scale: Auto | Magnifying glass with “A” written on its viewport |
| Full screen | Rectangle, with four arrows in the cardinal directions inside it pointing outward |
